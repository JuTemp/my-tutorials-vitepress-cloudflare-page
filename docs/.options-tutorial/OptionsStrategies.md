# Options Strategies

## 期权基础

期权的价值 = 内在价值 + 时间价值

> 内在价值是 如果把持有的期权立即行权产生的价值
> 
> 时间价值是 期权价格中除了内在价值 剩余的价值 (不只是期权因为时间产生的价值)

::: info 相关缩写

平值期权 ATM 实值期权 ITM 虚值期权 OTM

看涨期权 Call 看跌期权 Put

做多 Long 做空 Short

隐含波动率 Implicit Volatility (iv)

:::

平值期权的内在价值最大

**只要是买入期权，就是在做多波动率；只要是卖出期权，就是在做空波动率**

::: info 举例
都认为标的价格会上涨
  - Long Call 投资者认为iv偏低 符合低买的投资原则
  - Short Put 投资者认为iv偏高 符合高卖的投资原则
:::

期权对于买方来说，是一种损耗性资产，时间的流逝对买方是不利的；

对于卖方来说，时间是他的朋友，随着时间流逝，期权的价值会逐渐减少，如果最后OTM，则完全转化为卖方的收益。

iv上升，call put 价格均上升

## Black-Scholes 模型

::: details 前提假设
- 欧式期权（只能到期执行）**欧式期权**
- 没有交易费用和税收
- 没有红利支付 也没有其他分配
- 无风险利率`r`为常数而且对所有到期日都相同
- 投资者能以无风险利率无限量借入或贷出资金
- 不存在无风险套利机会 **充分定价**
- 标的物可以被自由买卖，可以做空，完全无限可分 **双向交易**
- 标的物交易是连续的，而且符合*随机游走的集合布朗运动*
:::

$$

\frac { \partial f } { \partial t } + rS \frac { \partial f } { \partial S } + \frac { 1 } { 2 }{ \sigma }^{ 2 }S^{ 2 } \frac { \partial ^2 f } { \partial S^2 }  = rf

$$

::: info 其中
标的物价格 $S$ 期权价格 $f$ 时间 $t$ 无风险利率 $r$ 波动率 $\sigma$ 
:::
